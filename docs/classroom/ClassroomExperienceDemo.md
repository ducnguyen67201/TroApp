# Classroom experience prototype

Open [ClassroomExperienceDemo.html](ClassroomExperienceDemo.html) in a browser, or
serve this directory locally. The prototype explores a student classroom with
colorful class cards, a lesson detail panel and original illustrations inspired by
the two education UI references supplied by the user.

Use the student/teacher switch to compare the two experiences. Select a class to
inspect its lesson and materials. The prototype includes local interactions for
exploring student work and teacher preparation, with Vietnamese and English text.
The microphone stays in the sidebar; there is no redundant page-name or machine
status bar above the content.

All classes, participants and lesson states are sample data. Preparation, invites,
session controls and submissions are demonstrations in memory. Reloading or
resetting restores the sample state. The prototype changes no backend, model service or real classroom. Its approved
visual direction is now used in the production classroom renderer; see
[Desktop UI](../DesktopUi.md). Downloadable examples are generated locally.
